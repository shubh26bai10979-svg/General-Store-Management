# Project Statement

## Project Title
**General Store Management Software**

## Problem Statement

Small general stores often need to keep track of basic sales and billing operations. For a simple store, maintaining the total of a customer's purchase and keeping track of which products have been sold can be repetitive when done manually.

The purpose of this project is to create a basic Python-based management program that can perform these tasks through a simple command-line interface. The system allows the store user to select products, calculate the bill, complete the transaction and view a summary of sales made during the current program session.

## Scope of the Project

The project focuses on the basic operations required for a small general store:

- Displaying a fixed list of products and prices
- Selecting products using product codes
- Calculating the total amount of a bill
- Allowing multiple products to be added to one bill
- Recording the quantity of each product sold during the session
- Storing completed bill totals in memory
- Displaying the current sales history
- Providing a simple menu to control the program

The project is intended as an academic Python application and does not attempt to replace a complete commercial billing system.

## Target Users

The primary target user is a small-store owner, shopkeeper or cashier who needs a basic console-based tool for simple billing and sales tracking.

It can also be used by students as an example of how basic Python programming concepts can be combined to solve a practical problem.

## High-Level Features

1. **Main Menu**  
   Provides options for billing, checking history and exiting.

2. **Billing Module**  
   Displays products and prices, accepts product codes and calculates the bill total.

3. **Sales History Module**  
   Shows product-wise quantities sold and the totals of completed bills during the current session.

4. **Input Validation for Menu/Product Codes**  
   Invalid numeric menu choices and product codes are rejected with a message asking the user to enter a valid operation.

5. **Session-Based Data Tracking**  
   Product quantities and completed bill totals are maintained while the program is running.

## Expected Outcome

The completed program provides a working command-line solution for basic store billing and sales tracking. It demonstrates the use of Python lists, functions, loops, conditional statements, user input and basic program control flow.
